Library & downloads

Where Octo writes downloaded songs and how it organizes them on disk.

Storage

Where downloads go
Navidrome library
This server has more than one library. Pick the one Octo should download into; otherwise it uses whichever Navidrome lists first.
Auto-detect download path from Navidrome
Octo asks Navidrome where its music folder is and writes there, so downloads always land where Navidrome scans. Only adopts a path Octo can see; otherwise it uses the field below.
Download path override / fallback
Path INSIDE the Octo container where downloaded files land (default /music, backed by the DOWNLOAD_PATH bind mount). To move the library on the host, change DOWNLOAD_PATH in .env instead; a host path like E:\Media\Music does not work here. With auto-detect on, this is only used until Navidrome's folder is detected.

Downloads

Where a starred song's permanent copy comes from, and when Octo fetches it.

Source

Download source
Soulseek gives lossless FLAC but depends on a peer having the file. YouTube always resolves but is lossy MP3, fetched through the yt-dlp shim. "Soulseek, then YouTube" tries FLAC first and falls back to MP3 only when no peer delivers. Same setting as DOWNLOAD_SOURCE in .env (Soulseek / YouTube / SoulseekThenYouTube); set it in either place, this one wins.
Download a song when starred
Works in every storage mode.
Download an album when starred
Star a whole album to fetch every track. Downloads run one at a time, so a full album takes a while.
Wait for lossless on first play
Permanent mode only. Off, a track plays straight away and the lossless copy turns up as its own library track once the scan finds it. On, the first play waits for the lossless file, which can take minutes and which most players give up on.
Lossless wait timeout seconds
Only with the wait on. 0 waits as long as the fetch needs. Above 0, playback falls back to the streaming preview after this many seconds while the download finishes in the background; some players refuse the preview on a track advertised lossless.

YouTube preview

Sidecar service that resolves YouTube audio for instant streaming.

Shim

Shim URL
The yt-dlp sidecar. Default works inside the docker network.

How it works

The shim is its own container running yt-dlp behind a tiny Flask wrapper. Process isolation keeps yt-dlp's quirks — and YouTube's frequent extractor breakage — from affecting Octo. Concurrent yt-dlp slots and cache size are configured via env vars on the yt-dlp-shim service in docker-compose.yml.

Raw config

Edit the settings file directly. Same JSON the form-by-form UI writes to — useful for power-users who'd rather hand-write a section than click through tabs, or for diffing/copying config across hosts.

File path

The file lives at /app/config/settings.json inside the container. The host bind-mount is at ./octo-config/settings.json next to your docker-compose.yml — you can vim/nano it there too. Changes hot-reload within ~500ms; settings flagged restart-required still need a restart.

settings.json

Top-level keys: Subsonic, Library, Soulseek, YouTube, LastFm. Anything you set here overrides the corresponding env var until removed.

Config sources

What value the app actually sees for each setting, after merging env vars and the settings file. Most settings now apply the moment you save. The few that cannot are marked restart required where you change them: the download path, the slskd connection, and the shim URL are all read once while the app starts.

Resolution order (highest first)

  1. settings.json — what the admin UI writes to. Highest priority.
  2. Environment variables — set in docker-compose.yml / .env at container startup.
  3. appsettings.json — built-in defaults shipped with the image.

About

What this is and where things live.

Octo is a Subsonic API proxy that augments your existing Navidrome library with discovery and on-demand downloading. Search includes external recommendations alongside your local songs; "Radio" on any song fans out via Last.fm and previews via YouTube; star a song you don't own and Octo grabs it via Soulseek.

Version

You are running Octo unknown. Include this in any bug report. Releases are dated, so 2026.07.29 is the release cut on that day.

Settings file

Anything you change in this UI is persisted to /app/config/settings.json. That file overrides env vars on next read. Editing it by hand also works — changes hot-reload.

Hot-reload vs restart

Most settings (storage mode, folder structure, filters) take effect immediately. Settings flagged restart required bake into HTTP clients at startup; use the Restart button in the sidebar to apply them.

Sign in to browse
Browsing folders needs a Navidrome admin account. Octo checks it with your Navidrome server and never stores it.
